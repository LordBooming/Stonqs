## 💼 Key Features

### 📊 True Performance Numbers

Most portfolio trackers show you simple gains or losses, but that's misleading. Stonqs uses **Time-Weighted Return (TWR)** and **Money-Weighted Return (XIRR)** - the same professional methods used by financial advisors. This means you see your real annualized return, accounting for when you added or removed money. No more guessing if you're beating the market.

### 🌍 Multi-Currency Support

Do you hold investments in USD, EUR, GBP, or even Bitcoin? Stonqs handles all currencies without breaking a sweat. Each account can be in its own currency, and Stonqs converts everything to your base currency for a unified view. Exchange rates update automatically when you're online.

### 🏦 Broker CSV Import

Tired of manually entering every trade? Stonqs can import transaction history from your broker's CSV files. Simply export your transactions from your broker's website as a CSV, then drag the file into Stonqs. It cleans up the data and categorizes everything for you. Works with most major brokers.

### 🔒 Complete Privacy - Your Data Never Leaves Your PC

This is the core promise of Stonqs. There is **no cloud sync, no telemetry, no login, no account creation**. Your portfolio data is stored in a local database file on your hard drive. Even if you're offline, everything works perfectly. You own your data - nobody else can even see it.

### 📱 Clean, Modern Interface

Stonqs has a user-friendly desktop interface built with modern technology. It's not a boring spreadsheet - it's a visual, interactive tool with charts, graphs, and color-coded performance indicators. Dark mode included for late-night investing reviews.

## ❓ Frequently Asked Questions

### How is Stonqs different from online trackers like Personal Capital or Mint?

Those services require you to create an account and upload your financial data to their servers. Stonqs is 100% local - your data never leaves your machine. Plus, Stonqs is completely free, while many online services have premium tiers.

### Is Stonqs really free?

Yes, completely free. It's open-source software, which means the code is publicly available for anyone to audit. You'll never see ads, upsells, or "pro" paywalls. It's built by the community, for the community.

### Can I track crypto in Stonqs?

Absolutely. You can create accounts in any currency, including cryptocurrencies like Bitcoin, Ethereum, etc. Treat them like any other asset in your portfolio.

### What does "TWR" and "XIRR" mean in simple terms?

- **TWR (Time-Weighted Return)** answers: "How did my investments themselves perform, ignoring my deposits and withdrawals?" It's great for comparing against market benchmarks.
- **XIRR (Money-Weighted Return)** answers: "What's my actual personal return on the money I put in?" It accounts for timing - so if you added more money at the right time, your XIRR will be higher.

Stonqs shows you both, so you get the complete picture.

### Will Stonqs ever go paid or shut down?

As open-source software, Stonqs is here to stay. Even if the original developer stops working on it, the community can continue development. The code is permanently available on GitHub.

## 🛠️ Troubleshooting

**Problem: The app won't install on my PC.**

Make sure you're downloading the correct file for your system (64-bit Windows 10/11). If you see a security warning from Windows SmartScreen, click "More Info" then "Run Anyway" - this is normal for open-source apps that haven't been signed with a commercial certificate.

**Problem: I can't see my imported CSV transactions.**

Ensure your CSV is formatted as "Date, Action, Symbol, Quantity, Price, Fees." Common brokers export this format by default. If it's different, try adjusting the column order or use the import mapping wizard in Stonqs.

**Problem: The exchange rates aren't updating.**

Stonqs needs internet access to fetch rates. Check your connection, then go to Settings > Exchange Rates and click "Refresh." If you're offline, the last known rates will continue to be used.

**Problem: I accidentally deleted my portfolio.**

Check the "Backups" folder inside the Stonqs data directory (usually in Documents/Stonqs/Backups). Stonqs automatically creates daily backups - just restore the most recent one.
